Etapix 0.1.0 para Linux (Ubuntu 22.04 ou mais novo, x86_64)

COMO INSTALAR
1. Descompacte o arquivo:            tar -xzf Etapix-Linux-x86_64.tar.gz
2. Entre na pasta e rode o instalador: cd etapix && ./instalar.sh

Não precisa de sudo: tudo fica na sua pasta pessoal. O Etapix aparece no menu de
aplicativos e também abre pelo terminal com o comando "etapix". O instalador também
registra o conector do Etapix no Claude Code e no Codex, se estiverem instalados.

ARQUIVOS .MPP
O Etapix abre, cria e salva arquivos .mpp e Project XML (.xml) no Linux por conta própria,
sem o Microsoft Project.

FONTES DO WINDOWS
Em Tarefa > Fonte, Times New Roman, Arial, Courier New, Calibri e Cambria aparecem quando
há uma fonte livre de mesma largura instalada (mostrada entre parênteses); Tahoma e Verdana
usam a DejaVu Sans, a mais parecida. Para ter todas no Ubuntu:
  sudo apt install fonts-liberation fonts-crosextra-carlito fonts-crosextra-caladea fonts-dejavu

DESINSTALAR
  ~/.local/share/etapix/desinstalar.sh
